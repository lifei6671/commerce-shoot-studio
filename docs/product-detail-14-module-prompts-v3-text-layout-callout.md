# 商品详情页 14 模块 Prompt 生成文档 v3：画面文字排版 + 条件标注版

> 适用模块：商品菜单 / 商品详情图生成流程
> 适用文件：`desktop/src-tauri/src/services/prompts/product_detail_scene_prompt.toml`
> 核心修正：主标题、副标题、参数表、SKU 名称、线性标注标签都属于**画面内文字生成指令**；其中只有“线性标注标签”需要指向商品元素，不能把所有文字都当成 tooltip 标签。
> 输出契约：每个模块仍只输出三类数据：`image_type`、`image_prompt`、`copy_requirements`。

---

## 1. 当前结论

原 v2 已经把“标签”修正为 tooltip / callout 类型的线性标注，但还不够：

- `主标题` 不是普通备注，而是让生图模型在画面中生成的大号标题文字。
- `副标题` 不是普通备注，而是让生图模型在画面中生成的辅助说明文字。
- `参数表文字`、`尺寸文字`、`SKU 名称`、`角度名称`、`成分名称`也都是画面内文字。
- `线性标注标签` 只是画面内文字的一种特殊类型：它必须有线条、锚点和被指向元素。

因此，`copy_requirements` 必须从“文案内容”升级为“**用户可编辑的画面文字与排版要求**”。

---

## 2. 三类输出数据定义

| 字段 | 定义 | 是否给用户编辑 | 是否控制画面文字 |
| --- | --- | --- | --- |
| `image_type` | 当前模块的简单核心描述，用于列表、卡片标题和方案识别 | 可展示，不建议编辑 | 不直接控制文字生成 |
| `image_prompt` | 发给生图模型的核心画面 Prompt，描述商品、场景、构图、光影、文字安全区和产品锁定 | 默认隐藏 | 必须要求模型执行 `copy_requirements` 中的文字和排版 |
| `copy_requirements` | 用户可查看、可修改的画面文字内容与排版要求 | 必须可编辑 | 是主标题、副标题、参数文字、标注标签的主要控制入口 |

重要约束：

1. 不新增第四个字段，仍保持当前 PromptPlan 解析结构。
2. `copy_requirements` 中的主标题、副标题、表格文字、标注文字，都应被下一步生图任务作为画面内文字生成要求使用。
3. `image_prompt` 不应只写“预留文案空间”，而应写“按 copy_requirements 生成清晰可读的画面内文字”。
4. 如果后续模型中文字生成质量不稳定，可以在工程上增加后期叠字策略；但本 Prompt 契约本身应明确要求模型生成画面文字。

## 3. 画面文字类型区分

### 3.1 主标题

用途：传递当前图片的第一信息层级。

特点：

- 字号最大。
- 位置固定在安全区。
- 不需要指向线。
- 不应贴近商品边缘。
- 不应遮挡商品主体。

### 3.2 副标题

用途：补充主标题，解释使用场景、核心收益、对比逻辑或信息说明。

特点：

- 字号小于主标题。
- 通常紧贴主标题下方或右侧。
- 不需要指向线。
- 信息密度比主标题高，但不能变成长段落。

### 3.3 结构化信息文字

包括：参数表、尺寸值、尺码、SKU 名称、角度名称、步骤名称、配件名称、成分名称。

特点：

- 可以是表格、卡片、尺寸线文字、角度 caption、步骤 caption。
- 不一定需要指向线。
- 适合规格图、参数表、系列图、配件图、成分图。

### 3.4 线性标注标签

用途：类似 HTML tooltip / annotation / callout，用线条指向商品可见元素。

正确结构：

```text
商品可见元素  ← 细线 / 折线 / 点状锚点  →  简短说明文字
```

特点：

- 必须有明确可见锚点。
- 必须有线条或短折线。
- 必须指向商品、结构、局部、尺寸刻度、配件、SKU、成分示意或对比区域。
- 不能指向空气、背景、抽象概念或不可见属性。
- 不是所有模块都需要。

## 4. `copy_requirements` 标准结构

每个模块的 `copy_requirements` 建议统一生成以下结构，方便用户理解和修改。

```text
主标题: "……"
主标题排版: 位置=……；字号=……；字体=……；字重=……；颜色=……；对齐=……；安全边距=……；最大行数=……
副标题: "……"
副标题排版: 位置=……；字号=……；字体=……；字重=……；颜色=……；对齐=……；与主标题间距=……；最大行数=……
结构化信息: ……
标注标签: 使用 / 不使用 / 暂不使用，原因=……
标注 1: "……" -> 指向: ……
标注 2: "……" -> 指向: ……
线条样式: ……
文字生成要求: 主标题、副标题、结构化信息和已启用标注必须作为画面内清晰可读文字生成；禁止生成未列出的额外文字、乱码、伪文字、错误参数或虚假认证。
目标语言: 中文 / English / 其他目标语言
缺失信息: ……
```

如果当前模块不需要结构化信息，可写：

```text
结构化信息: 不使用。
```

如果当前模块不需要线性标注标签，可写：

```text
标注标签: 不使用；本图只生成主标题、副标题或结构化信息，禁止生成指向线、箭头、悬浮 tooltip 标注。
```

如果信息不足导致不能使用标签，可写：

```text
标注标签: 暂不使用；缺少可标注信息，需补充[尺寸/容量/SKU/配件/成分/工艺/对比状态]后再生成线性标注。
```

## 5. 全局画面文字排版规则

### 5.1 字号层级

建议用相对比例表达，让不同画幅都能稳定工作。

| 文字类型 | 建议字号 | 说明 |
| --- | --- | --- |
| 主标题 | 画面高度的 7%-12% | 首屏、核心卖点图可偏大；参数表、细节图可偏小 |
| 副标题 | 画面高度的 3%-5% | 层级必须弱于主标题 |
| 表格/参数文字 | 画面高度的 2.2%-3.5% | 保证可读，不拥挤 |
| 角度/SKU caption | 画面高度的 2.5%-4% | 放在对应商品图下方或旁边 |
| 线性标注文字 | 画面高度的 2.2%-3.2% | 必须短，不超过 12 个字 |

### 5.2 安全边距

```text
画面文字距离图片边缘至少保留 6%-10% 安全边距。
主标题和副标题不得压到商品主体、人物面部、Logo、重要纹理和标注线。
线性标注标签必须放在商品外侧留白区，线条不要穿过商品中心区域。
```

### 5.3 字体风格

模型不一定能精准复刻字体名称，因此应描述字体气质，而不是依赖具体字体文件。

可用描述：

```text
粗体无衬线体、窄体无衬线体、现代几何无衬线体、优雅衬线体、圆润无衬线体、科技感无衬线体、杂志感标题体
```

禁止描述：

```text
必须使用某个具体商业字体文件
```

### 5.4 颜色与对比

```text
文字颜色必须与背景形成清晰对比。
浅色背景优先使用深灰/黑色文字。
深色背景优先使用白色/浅灰文字。
可以使用半透明文字底板、轻微投影或描边提升可读性，但不能像低质广告贴纸。
```

### 5.5 模型文字约束

所有模块的 `image_prompt` 都应包含以下约束：

```text
画面内文字必须严格按照 copy_requirements 生成，主标题、副标题、结构化信息和已启用标注文字必须清晰可读；文字使用目标语言；禁止生成乱码、伪文字、拼写错误、未列出的营销词、虚假参数、虚假认证、虚假销量、虚假评价或品牌历史。
```

如果目标语言是中文，建议在最终生图 Prompt 中把图片内文字用中文引号包裹，例如：

```text
主标题文字为「潮酷运动无袖背心」，副标题文字为「撸铁出街都好穿」。
```

# 7. 14 个模块 Prompt 规则

---

## 7.1 `hero_visual`｜首屏主视觉

### 场景目标

建立第一眼商品识别，传递最核心购买理由。首屏要强冲击、强商品主体、强标题层级。

### 线性标注策略

禁用。首屏主视觉不生成 tooltip、指向线、箭头或悬浮标签。

### `image_type`

```text
首屏主视觉: 传递[商品最核心购买理由]
```

### `image_prompt`

```text
生成一张高清电商首屏主视觉图，使用用户选择的爆款风格作为整体视觉基调，文字使用目标语言。以商品图中的商品主体为唯一核心主体，完整展示商品最具识别度的角度，突出商品的第一购买理由。商品位于画面视觉中心或中央偏上，占画面约 35%-55%。背景根据商品定位选择简洁、有记忆点但不喧宾夺主的商业场景。画面需要直接生成主标题和副标题文字，不只是预留空白；标题区域位于下方、左侧或右侧安全区，背景需保持干净，确保文字清晰可读。整体构图要具备首屏点击感、商品识别度和平台电商商业感。

画面内文字必须严格按照 copy_requirements 生成：主标题为最大文字层级，副标题紧跟主标题；禁止生成 copy_requirements 之外的额外文字。本图不生成线性标注标签，不生成指向线、箭头、气泡标签或 tooltip 标注。

镜头角度：根据商品形态选择正面、45 度或轻微仰视，确保轮廓完整、比例自然。
光影设置：柔和主光打亮商品关键区域，弱辅光降低硬阴影，必要时使用轮廓光强化商品边缘和高级感。
【产品锁定】严格保留产品原始外观、颜色、结构、比例、Logo 位置、图案和可见细节，禁止新增、删除或修改商品主体；禁止添加未提供的配件、赠品、认证标识、参数数值或品牌信息；光影、背景和道具必须自然融入场景，不得遮挡商品核心区域。
```

### `copy_requirements`

```text
主标题: "提炼一个最强购买理由，建议 6-12 个字"
主标题排版: 位置=画面下方居中或左下安全区；字号=画面高度的 9%-12%；字体=粗体无衬线体或锐利商业标题体；字重=加粗；颜色=与背景强对比；对齐=居中或左对齐；安全边距=距离边缘至少 8%；最大行数=1-2 行。
副标题: "补充使用场景或体验收益，建议 8-18 个字"
副标题排版: 位置=主标题正下方；字号=画面高度的 3.5%-5%；字体=干净无衬线体；字重=中等；颜色=弱于主标题但清晰可读；对齐=跟随主标题；与主标题间距=主标题高度的 15%-25%；最大行数=1 行。
结构化信息: 不使用。
标注标签: 不使用；首屏主视觉只生成主标题和副标题，禁止生成指向线、箭头、悬浮标签或 tooltip 标注。
文字生成要求: 主标题和副标题必须作为画面内清晰可读文字生成；禁止乱码、伪文字、额外促销词、虚假参数或虚假认证。
目标语言: 使用用户选择的目标语言。
缺失信息: 如果核心卖点不足，写“核心卖点需补充”。
```

## 7.2 `core_selling_point`｜核心卖点图

### 场景目标

只放大一个核心卖点，让用户一眼理解“为什么值得买”。

### 线性标注策略

条件启用。只有当核心卖点对应商品可见结构、局部、材质线索、功能区域或外观部位时，才使用 1-3 个线性标注标签。抽象体验卖点不使用标签。

### `image_type`

```text
核心卖点图: 突出[单一核心优势]
```

### `image_prompt`

```text
生成一张高清电商核心卖点图，使用用户选择的爆款风格作为视觉基调，文字使用目标语言。画面只聚焦商品的一个核心卖点，通过商品主体、局部强调、辅助视觉元素和清晰留白来强化理解。商品保持清晰完整，占画面约 35%-50%，卖点相关区域必须无遮挡，并放在最容易被线条指向的位置。构图采用“商品主体 + 卖点文字说明区”的电商信息图结构。

画面需要直接生成主标题和副标题文字。主标题突出单一核心优势，副标题解释优势带来的使用价值。文字区域位于画面上方、左侧或右侧安全区，与商品主体保持清晰分区。

如果 copy_requirements 启用线性标注标签，则画面中生成 1-3 个线性标注标签：使用细线或短折线从标签文字指向商品可见卖点区域，线条端点落在被标注部位，标签文字位于商品外侧留白区；每个标签只指向一个元素，标签之间不交叉、不重叠、不遮挡商品主体。若 copy_requirements 写明不使用标注标签，则禁止生成指向线、箭头、悬浮 tooltip。

画面内文字必须严格按照 copy_requirements 生成，禁止生成未列出的额外文字、错误参数或未提供信息。
镜头角度：选择最能体现该卖点的角度，例如正面、侧面、斜侧面、俯视或局部近景。
光影设置：主光集中打亮卖点区域，背景保持简洁，使用适度对比让用户第一眼看到优势点。
【产品锁定】严格保留产品原始外观、颜色、结构、比例、Logo 位置、图案和可见细节，禁止新增、删除或修改商品主体；禁止添加未提供的配件、赠品、认证标识、参数数值或品牌信息；光影、背景和道具必须自然融入场景，不得遮挡商品核心区域。
```

### `copy_requirements`

```text
主标题: "提炼单一核心卖点，建议 6-12 个字"
主标题排版: 位置=画面上方左侧或右侧信息区；字号=画面高度的 7%-10%；字体=粗体无衬线体；字重=加粗；颜色=与背景强对比；对齐=左对齐优先；安全边距=距离边缘至少 8%；最大行数=1-2 行。
副标题: "解释该卖点带来的具体使用价值，建议 10-20 个字"
副标题排版: 位置=主标题下方；字号=画面高度的 3%-4.5%；字体=干净无衬线体；字重=常规或中等；颜色=弱于主标题；对齐=跟随主标题；与主标题间距=主标题高度的 15%-25%；最大行数=1-2 行。
结构化信息: 可选；如果卖点包含 2-3 个短信息点，可使用小号信息短句，但不能变成参数表。
标注标签: 条件使用；只有卖点对应商品可见结构/局部/区域时使用 1-3 个线性标注标签。
标注 1: "短标签文字" -> 指向: 商品上与核心卖点直接相关的可见位置。
标注 2: "短标签文字" -> 指向: 商品上第二个可见支撑点。
线条样式: 细线或短折线，端点小圆点，标签文字放在商品外侧留白区，不遮挡商品主体。
文字生成要求: 主标题、副标题、结构化信息和已启用标注必须作为画面内清晰可读文字生成；禁止乱码、伪文字、额外促销词、虚假参数或虚假认证。
目标语言: 使用用户选择的目标语言。
缺失信息: 如果卖点不可见或证据不足，标注标签写“不使用”。
```

## 7.3 `usage_scene`｜使用场景图

### 场景目标

让用户代入真实使用方式，理解商品在具体生活场景中的价值。

### 线性标注策略

默认禁用，少量条件启用。只有当画面中存在明确的使用动作、接触点、安装点、收纳点或操作点时，才允许 1-2 个标注。一般生活方式图不使用 tooltip。

### `image_type`

```text
使用场景图: 展示[真实使用场景价值]
```

### `image_prompt`

```text
生成一张高清电商使用场景图，使用用户选择的爆款风格作为视觉基调，文字使用目标语言。画面展示商品被真实、合理地使用，人物、手部、环境或生活道具只作为辅助，不能抢占商品主体。商品必须清晰可见，占画面约 25%-45%，使用方式自然可信，不制造错误使用方式。

画面需要直接生成主标题和副标题文字。主标题强调场景价值，副标题说明适用人群、使用时机或体验收益。文字区域建议位于画面上方或下方安全区，不遮挡人物面部、手部动作和商品主体。
```

# 10. 验收标准

1. 每个模块仍只返回 `image_type`、`image_prompt`、`copy_requirements`。
2. `copy_requirements` 必须包含主标题、副标题的文字内容和排版信息。
3. 主标题和副标题必须被定义为画面内文字生成要求，不只是后期备注或留白说明。
4. 每个模块必须明确“标注标签：使用 / 不使用 / 暂不使用”。
5. 使用标注标签时，必须有标签文案、指向位置和线条样式。
6. 不使用标注标签时，必须明确禁止生成指向线、箭头、气泡标签或 tooltip 标注。
7. 参数表、尺寸值、角度 caption、SKU 名称、配件名称、成分名称属于结构化信息文字，不自动等同于 tooltip 标签。
8. 缺少必要事实时，必须输出“需补充”，不得编造参数、尺寸、容量、材质、成分、SKU、配件、工艺、认证、功效、价格、产地或品牌历史。
9. `image_prompt` 必须包含产品锁定段落。
10. `image_prompt` 和 `copy_requirements` 不允许残留未填充 `{...}` 占位符。
